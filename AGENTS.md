# LINE Sticker Studio (development repo)

This repo publishes one agent skill, `skills/line-sticker/`, which is self-contained: users install that folder
alone (Codex `skill-installer`, or a copy into `~/.codex/skills/` / `~/.claude/skills/`) and run its CLI from
their own work folder. Human guide: `README.md`. Workflow the skill teaches: `skills/line-sticker/SKILL.md`.

## Conventions

- Everything the skill needs at runtime lives inside `skills/line-sticker/`: `sticker.py`, `studio/`, `fonts/`,
  `style/`, `examples/`, `requirements.txt`, `LICENSE.txt` (a copy of the root `LICENSE`).
- Sticker sets live in `./themes/` of the folder the CLI runs from (`LINE_STICKER_THEMES` overrides);
  code paths into the skill go through `studio.theme.ROOT`, and hints printed to people use `studio.theme.CLI`.
- `themes/<id>/theme.yaml` is the source of truth; `prompts.md` is generated by `prompts`.
- Images: `art/NN.png` is text-free art for font-lettered sets; `source/NN.png` is the full sticker
  (composed by `build`, or drawn whole by the image model when a set has no `lettering:`).
- `studio/` keeps one job per module: `theme` (load/validate), `prompts`, `importer`, `generate`, `lettering`
  (Thai text rendering via HarfBuzz), `compose` (art + caption), `build`, `images`, `duplicates`,
  `scaffold`, `doctor`, `cli`.
- Tests: `pip install pytest`, then `python -m pytest -q tests` from the repo root.
